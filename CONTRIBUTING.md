# Como contribuir

Obrigado por contribuir para o Replica Universal.

- Abra uma issue com objetivo, contexto e evidências reproduzíveis.
- Não inclua código ou assets proprietários de aplicativos analisados.
- Preserve `LICENSE` e `NOTICE.md` e identifique mudanças relevantes.
- Para alterações em skills, mantenha `name` e `description` no frontmatter.
- Rode `python3 -m unittest discover -s tests -v` e `python3 replica.py check`.
- Uma alteração de adapter deve preservar o comportamento canônico de `AGENTS.md`.
- Nunca inclua segredos, tokens, dados pessoais ou material sem licença.
